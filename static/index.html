This uses a read-only export request; manual file exports are not needed.

    Import / Export Tally data
    
        
        
    
        
    
        
    Import from Tally export files
          
    A folder holding Master.xml and optionally DayBook.xml / Transactions.xml exported from TallyPrime. The files are only read. Importing again updates the same company and changes nothing that is unchanged.
    
          
          
        
    
        
    Import live from a running TallyPrime (read-only)
          
    Reads every master, voucher, bill and balance with read-only requests, one at a time, then compares the result with TallyPrime's own Trial Balance. It can load TallyPrime heavily on a large company.

    Export the active company as Tally XML
          
    Writes every group, ledger, voucher, bill and inventory line. It is checked by re-importing it into a fresh company. TallyForge never writes to TallyPrime; whether TallyPrime accepts the file has not been tested.
